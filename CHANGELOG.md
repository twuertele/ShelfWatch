# Changelog

## 0.2.1

- Lower the minimum supported Home Assistant version to the tested 2026.1.2
  release.
- Add a reproducible Home Assistant 2026.1.2 compatibility test stack.
- Add correctly sized standard and high-DPI ShelfWatch brand assets.

## 0.2.0

Initial public ShelfWatch MVP:

- Home Assistant UI setup for multiple Koha / LMSCloud accounts
- current checkout and due-date sensors
- configurable due-soon window and update interval
- local-midnight due-date recalculation
- optional reading-progress Todo list
- optional automatic completion and retained history for returned media
- German and English translations
- reauthentication support
- local ShelfWatch branding
